# Calendario Familia

PWA familiar para consultar los turnos de Alex y María y los planes de la familia.

- **Versión actual:** Premium BETA 1.2
- **Enlace:** https://tiizon.github.io/calendario-familia/
- Los eventos y notas se guardan en cada dispositivo (todavía sin sincronización).
- Instalar en iPhone: abrir el enlace en Safari → Compartir → Añadir a pantalla de inicio.
